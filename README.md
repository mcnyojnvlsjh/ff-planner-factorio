## Overview

Factorio Freight Forwarding Planner is a companion tool for the Freight Forwarding Factorio mod, helping players design interplanetary freight routes, calculate container throughput requirements, balance planetary export and import schedules, and plan train network capacity for the mod's multi-planet logistics challenges.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Factorio Freight Forwarding Planner** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Route Designer** | Design freight route networks between planets and orbital hubs |
| **Throughput Calc** | Calculates required containers per minute for production targets |
| **Balance Planner** | Balances planetary export surplus against import requirements |
| **Train Capacity** | Plans rail network capacity to support freight route throughput |
